# 使用教程

面向第一次使用的用户：先看“5 分钟上手”，后面按需查进阶功能。

![界面总览](images/overview.png)

## 界面一览

| 区域 | 内容 |
|---|---|
| 顶栏 | 芯片下拉、导出 CSV/Markdown、保存/载入工程、导出封装图 |
| 左栏 | 系统配置开关 + 资源目录（顶部可过滤，如输入 `PWM` / `UART`） |
| 中间 | 封装图；滚轮缩放，按住拖动平移 |
| 右栏 | 已分配资源：改映射组、切模式、加/删可选信号、解除 |
| 底部 | 状态栏：已用 / 锁定 / 冲突 / 剩余 IO |
| 冲突横幅 | 出现冲突时显示在状态栏上方，提示点红色引脚处理 |

## 1. 选芯片

顶栏下拉按厂商/系列分组，选择型号与封装。每颗芯片的配置在**当前会话内互相独立**；刷新页面即清空，需要留存请导出工程文件。

## 2. 分配引脚

### 方式 A：从封装图点引脚

点击引脚焊盘，弹出完整功能菜单（CubeMX 式）：

- **可用项**直接点击分配；
- **不可用项置灰**，括号里写明原因（悬停也有提示）；
- 有映射组的外设会出现“（映射组）”选项，点它直接整组切换；
- “设为 GPIO…”可给该脚起别名（如 `FLASH_CS`）。

![引脚菜单](images/pin-menu.png)

### 方式 B：从左侧资源目录

点资源名 → 自动挑一组可用落脚点并分配；再点一次解除。默认组被占时会**自动改用映射组**，底部日志会说明原因。带模式的外设（如 SPI0）会先弹出模式选择。

### 解除分配

三种方式任选：再点左侧资源；右栏该资源行的“解除”；点已占用的引脚 → “解除分配”。

## 3. 颜色与状态

**引脚颜色：**

| 颜色 | 含义 |
|---|---|
| 浅灰 | 空闲 |
| 分类色（蓝/紫/青/橙…） | 已分配，颜色对应外设类别 |
| 深灰 | 电源/固定引脚，不可分配 |
| 灰色虚线 | 被系统配置（调试口/晶振等）锁定 |
| 红色 | 冲突：同一脚被多个资源占用 |

**左栏色点**（未分配的资源才有）：

- 🟢 绿：默认组可以落；
- 🟡 黄：默认组被占，但映射组可落（一键分配会自动改走映射组）；
- 🔴 红：没有任何落脚点（悬停看缺哪些脚）。

## 4. 映射组（整组切换）

有些外设的复用是“一位寄存器切一整组”，不能混搭。例如 SPI0 的默认组在 PA 侧、映射组在 PB 侧。

- 左栏点分配时自动选择可用的一组；
- 右栏已分配行点“改用映射组 / 换回默认组”；
- 在引脚菜单里直接选带“（映射组）”的选项也可以。

## 5. 模式

带 `modes` 的外设可切换工作模式，右栏已分配行有下拉框：

- **SPI0**：主机·全双工3线 / 主机·半双工2线 / 从机·全双工4线 / 从机·半双工3线；
- **TMR0–TMR3**：PWM 输出 / 捕捉输入 / 外部计数（占脚）/ 内部定时中断（**不占脚**）。

切换模式时会尽量保留已添加的可选信号；如果新模式下保不住，会整体中止并说明原因。

## 6. 可选信号

必选信号之外的信号（如 UART0 的 MODEM 六信号、SPI0 主机模式的 SCS）按需添加：

1. 先分配资源；
2. 右栏该资源行点“＋ 添加信号”；
3. 菜单里选择引脚；不可用项置灰并给原因；
4. 已添加的可选信号旁有 `×`，可单独移除。

约束：部分信号必须同侧（如 UART0 的 DTR/DSR 共用一位映射），菜单会据此置灰。也可以在引脚菜单里直接添加标有“（可选信号）”的项（需先分配该资源）。

## 7. 系统配置

左栏顶部开关会占用固定引脚，例如：

- 两线调试口（SWD/SWCLK）；
- 外部复位 RST；
- 32.768kHz 晶振；
- RF 天线开关（PB16–21，官方当前建议默认关闭）。

勾选即占用对应脚；与已分配资源冲突时会标红并出现冲突横幅。关闭开关即释放。

## 8. GPIO

在引脚菜单选“设为 GPIO…”并输入别名（留空则显示为 GPIO）。右栏会列出 GPIO 行，可“清除”。

## 9. 视图操作与撤销

- **缩放**：鼠标滚轮（以指针位置为中心）；
- **平移**：按住画布拖动；移动超过 8px 才判定为拖拽，避免手抖吞掉点击；
- **撤销**：`Ctrl+Z`（Mac 为 `Cmd+Z`）。

## 10. 导出与工程文件

| 导出 | 内容 |
|---|---|
| CSV | 脚号、引脚、分配功能、信号、别名/备注、类别 |
| Markdown | 同上，表格形式，适合贴进设计文档 |
| 保存工程 | JSON：芯片标识 + 系统配置 + 资源分配 + GPIO；下次“载入工程”继续 |
| 导出封装图 | 当前芯片的 SVG（可放大、可插入文档） |

- 右栏点信号名可以给信号起别名（如把 `TXD` 标成 `DEBUG_TX`），导出时会带上；
- 载入工程会自动切到文件所属芯片；没有 `chipId` 的旧工程按“芯片名 + 封装”匹配，封装不一致会给出提示而不是静默。
- 配置只存在内存里，**刷新即清空**。

## 11. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点引脚没反应 | 拖动超过 8px 被当作平移；请直接点焊盘。也可从左侧资源目录分配 |
| 资源是红点 | 默认组与映射组都没有落脚点；悬停看缺脚，先解除占用或关闭系统开关 |
| 分配后引脚变红 | 出现冲突（常见于手工组合或旧工程）；点红色引脚，菜单里解除其中一个占用 |
| 刷新后配置没了 | 设计如此；请“保存工程”导出 JSON |
| 芯片不在下拉列表 | 数据文件未加入 `chips/manifest.js`（漏行会静默不显示）；见 [贡献指南](../CONTRIBUTING.md) |
| 与手册不一致 | 数据以公开手册为准；欢迎附页码提 issue / PR |

## 数据来源与边界

- 芯片数据来自公开数据手册（CH58x 系列：CH583DS1 V1.9，2025-04-10），逐脚核对；
- 工具只做资源规划与冲突校验，**不生成代码**；
- 新增芯片 / 修正数据：见 [CONTRIBUTING.md](../CONTRIBUTING.md)，字段定义见 [chip-data-schema.md](chip-data-schema.md)。
